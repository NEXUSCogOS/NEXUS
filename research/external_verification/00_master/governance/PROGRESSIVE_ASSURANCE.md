# NEXUS-EVA Progressive Assurance Policy

## A0 — Internal Experiment

External verification required: 0

Properly governed internal experiments may execute when their existing
methodological, safety and readiness requirements are satisfied.

NEXUS-EVA must not create an external-verification dependency merely for
ordinary internal experimentation.

## A1 — Externally Reviewed Result

Requirement:

>= 1 claim-appropriate independent verification mode

Permitted description:

"Externally reviewed under [specific verification mode]."

This does not automatically constitute independent scientific validation.

## A2 — Independently Supported Scientific Result

Target:

>= 2 complementary independent verification modes

Preferred combination:

L1 Scientific Independent Replication
+
L4 Clean-Room Reproduction

## A3 — Flagship Validated Claim

Target:

>= 3 complementary independent verification modes

Preferred combination:

L1 Scientific Independent Replication
+
L2 Independent Agent Evaluation
+
L4 Clean-Room Reproduction

## Software / Governance Claims

Claims concerning enforcement of software controls, authority boundaries,
fail-closed behaviour or system invariants require L3 Software/Formal
Assurance.

L1 or L2 does not automatically substitute for L3.

## Professional / Commercial Assurance

Institutional, governance, professional-assurance or commercial-readiness
claims require an appropriate L5 Professional Assurance process.

## L0 — Independent Protocol Review

L0 is strongly recommended before execution of experiments intended to
support:

- flagship claims;
- publication;
- grant applications;
- major scientific conclusions;
- consequential external claims.

L0 asks whether the proposed experiment can answer its stated research
question.

L0 does not establish that the underlying NEXUS capability is valid.

## Maximum Assurance

L0 + L1 + L2 + L3 + L4 + L5 represents the maximum broad assurance programme.

Completion of all six layers is NOT a universal prerequisite for
experimentation or for every research claim.
