# NEXUS Experiment Gate Evidence

This directory contains formal verified gate records.

A gate may be recorded PASS only when:

1. gate text exactly matches the canonical registry;
2. status is PASS;
3. reviewer is identified;
4. verification time is recorded;
5. evidence references are present;
6. referenced artifacts exist;
7. supplied SHA-256 hashes match;
8. contradictory evidence has been resolved.

Candidate evidence, textual similarity, prior claims and generated
publication reports are not sufficient.

No automated process may invent independent reviewer approval.
