# Engineering Studio Experiment Research Inbox

Structured experiment findings are delivered here for Research Assistant
comparison.

A request is not itself literature evidence.

Research Assistant comparisons must distinguish:

- CORROBORATING_PRIOR_FINDINGS
- CONTRADICTORY_PRIOR_FINDINGS
- ADJACENT_OR_MECHANISTICALLY_RELEVANT_FINDINGS

Correspondence strength must use:

- DIRECT_REPLICATION_ANALOGUE
- CLOSE_METHOD_ANALOGUE
- CONCEPTUAL_ANALOGUE
- MECHANISTICALLY_RELEVANT
- WEAKLY_RELATED
- NO_MEANINGFUL_COMPARATOR

If no close study exists, return:

NO_CLOSE_PRIOR_STUDY_FOUND

Internal experimental support is not equivalent to independent replication.
