# MASTER DIRECTIVE
# NEXUS SCIENTIFIC VALIDATION, RESEARCH ASSISTANT & STORAGE OPTIMISATION FRAMEWORK

## MISSION

Transform NEXUS into a continuously validated scientific AI research platform by creating an automated evidence, analysis, and documentation framework operating across all subsystems.

The objective is to produce a longitudinal research dataset demonstrating:

- system functionality
- reliability
- accuracy
- efficiency
- adaptation
- cognitive performance
- engineering improvement
- reproducibility
- scientific validity

The final output must support:

- technical papers
- academic collaboration
- PhD-level research evaluation
- industry demonstration
- future commercialisation

# PART 5
# STORAGE OPTIMISATION POLICY


PRIMARY OBJECTIVE:

Minimise local storage usage while maintaining operational capability.


Rules:


## LOCAL MACHINE

Only retain:

- active runtime files
- current databases
- required dependencies
- recent logs
- active models


## ICLOUD / EXTERNAL STORAGE

Move:

- historical evidence packs
- research corpus
- completed experiments
- archived logs
- old databases
- previous versions
- documentation


## ARCHIVE POLICY


Daily:

Compress completed evidence packs.

Weekly:

Move older evidence to archive storage.

Monthly:

Generate compressed research snapshot.
