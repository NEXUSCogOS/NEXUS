# Federation Ingress Architecture

**Status**: GROUNDED. `kernel.py::FederationKernel`, `ingress/validator.py`.

## The pipeline (as implemented, verified end-to-end)

```
raw_payload (dict)
  │
  ▼
ingress/validator.py :: ingest_raw_payload()
  ├── schema_version check (KNOWN_SCHEMA_VERSIONS)  -- rejects unknown versions explicitly
  └── institutional.contract.validate_report()      -- DAT.AI's own contract, fail-closed
  │
  ▼ (InstitutionalReport, schema-valid)
kernel.py :: FederationKernel.ingest_report()
  │
  ├── state/temporal.py :: classify_incoming_report()
  │     -- CURRENT / STALE / EXPIRED / OUT_OF_ORDER / DUPLICATE / CLOCK_SKEW_REJECTED
  │     -- report_log append (every attempt, accepted or not)
  │     -- if not accept: return here
  │     -- if DUPLICATE: return existing registry entry, no further processing
  │
  ├── evidence/resolver.py :: resolve_evidence_ref() per capability
  │     -- real filesystem check + hash baseline/drift
  │
  ├── kernel.py :: _is_contradictory()
  │     -- regression-without-explanation detection against prior registry state
  │
  ├── registry/models.py :: InstitutionRegistryEntry construction
  │     -- persistence/db.py :: upsert_registry_entry()
  │
  └── relevance/router.py :: assess_relevance() (only for explicitly-supplied RelevanceSignals)
        -- delegation/schema.py :: DelegationProposal
        -- persistence/db.py :: append_delegation()
```

## Why cross-package Python import, not a network/message-bus transport

No message bus or network transport exists anywhere in this NEXUS estate
(confirmed absent in the prior `FEDERATION_LINEAGE_GAP_MATRIX.md` mission).
Building one for F1 would be exactly the kind of "full AGI-like executive
kernel" scope the mission explicitly warned against. `systems/dat_ai` and
`systems/nexus_federation` are both on `PYTHONPATH` when the federation
runs; `ingress/validator.py` does `from institutional.contract import ...`
directly, which resolves to DAT.AI's real module. This is the smallest
mechanism that satisfies "consume DAT.AI's existing contract directly" —
a real transport layer (HTTP, a queue, a socket) is future work once more
than one institution needs to report concurrently from separate processes.

## Storage

SQLite (`persistence/db.py`), consistent with this estate's other
control-plane storage choices. Three tables: `institution_registry`
(latest state), `report_log` (append-only, full history, the basis for
restart recovery and observability), `delegation_log` (append-only),
`evidence_baseline` (drift-detection anchors).
